# Notebooks

Esta pasta contém notebooks Jupyter usados para exploração de dados, visualizações e experimentos didáticos do projeto.

## Convenção

- use notebooks para exploração, hipóteses, gráficos e análises interativas;
- mantenha a lógica reutilizável em scripts ou módulos dentro de `aplicacao`;
- registre no notebook o objetivo, a fonte dos dados, o ambiente e a conclusão;
- evite usar o notebook como único lugar para código necessário em execução repetida.

## Executar Jupyter

Na raiz do projeto, com o ambiente virtual ativado:

```powershell
python -m jupyter lab
```

Os notebooks devem usar o kernel associado ao ambiente:

```text
Python (ml-classificacao)
```
