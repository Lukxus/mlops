# Regressão linear simples

## O que queremos aprender

Entender como uma única variável pode ser usada para prever um valor numérico e quando uma reta é uma aproximação razoável.

## Versão básica

Usar dados pequenos ou sintéticos com uma relação conhecida, como horas de estudo e nota. Visualizar os pontos, a reta, as previsões e os resíduos.

## Versão complexa

Prever a latência de uma API a partir do número de requisições simultâneas, incluindo ruído, outliers e uma região em que a relação deixa de ser linear.

## Decisões a questionar

- Uma única variável é suficiente?
- A relação parece linear?
- O intercepto faz sentido?
- O modelo está extrapolando?
- Os resíduos parecem aleatórios?
- Um outlier está dominando a reta?
