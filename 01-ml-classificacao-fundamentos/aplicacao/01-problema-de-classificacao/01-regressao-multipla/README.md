# Regressão múltipla

## O que queremos aprender

Entender como várias variáveis explicativas formam uma previsão e como interpretar correlação, redundância e contribuição aparente.

## Versão básica

Prever preço de imóvel usando área, número de quartos e idade do imóvel.

## Versão complexa

Prever consumo de energia usando temperatura, horário, ocupação e carga histórica, introduzindo variáveis correlacionadas e uma variável que poderia causar leakage.

## Decisões a questionar

- As features trazem informação nova ou repetida?
- Os coeficientes são estáveis?
- Existe multicolinearidade?
- A variável está disponível no momento da previsão?
- A interpretação do coeficiente é válida sob as hipóteses do modelo?
