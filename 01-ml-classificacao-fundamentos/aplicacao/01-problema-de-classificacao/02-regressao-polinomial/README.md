# Regressão polinomial

## O que queremos aprender

Entender como adicionar curvatura pode representar relações não lineares e como isso aumenta o risco de overfitting.

## Versão básica

Usar dados sintéticos em formato de U, por exemplo `y = x² + ruído`, e comparar uma reta com polinômios de grau 2 e 3.

## Versão complexa

Prever demanda conforme temperatura usando graus 1, 2, 5 e 12, comparando ajuste no treino, desempenho em teste e comportamento fora da faixa observada.

## Decisões a questionar

- A curvatura é sustentada pelos dados ou criada pelo modelo?
- O grau escolhido generaliza?
- O modelo se comporta de forma absurda fora da faixa observada?
- A complexidade compensa o ganho?
