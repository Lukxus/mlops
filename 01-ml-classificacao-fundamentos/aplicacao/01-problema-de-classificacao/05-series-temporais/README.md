# Séries temporais

## O que queremos aprender

Entender por que a ordem temporal muda a preparação, a validação e a interpretação do modelo.

## Versão básica

Criar uma série com tendência e sazonalidade simples e comparar baseline ingênuo, média móvel e regressão com variáveis de tempo e lags.

## Versão complexa

Prever demanda ou latência com lags, janelas móveis, sazonalidade, mudanças de regime e drift, usando validação walk-forward.

## Decisões a questionar

- Estamos usando informação do futuro?
- O baseline temporal foi vencido?
- A sazonalidade é estável?
- O modelo funciona após uma mudança de distribuição?
- O horizonte de previsão é compatível com os dados disponíveis?
