# Regressão regularizada

## O que queremos aprender

Entender como penalizar coeficientes grandes pode reduzir overfitting e lidar com features correlacionadas ou numerosas.

## Versão básica

Gerar features correlacionadas e comparar regressão linear comum, Ridge e Lasso.

## Versão complexa

Criar um problema com muitas features, poucas observações úteis, variáveis irrelevantes e grupos de features correlacionadas.

## Decisões a questionar

- O problema é variância alta ou viés alto?
- Ridge deve preservar grupos de features correlacionadas?
- Lasso deve selecionar algumas features?
- O ganho vem de generalização ou apenas de uma divisão favorável?
- O hiperparâmetro foi escolhido sem contaminar o teste?
