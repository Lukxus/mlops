# Árvores de regressão

## O que queremos aprender

Entender como regras e divisões por faixas representam relações não lineares e interações sem exigir uma equação global.

## Versão básica

Prever latência usando regras simples por faixa de carga, comparando uma árvore rasa com uma reta.

## Versão complexa

Prever um valor em dados tabulares com interações entre variáveis, testando profundidade, folhas mínimas, ensemble e risco de overfitting.

## Decisões a questionar

- O modelo está decorando os dados?
- A profundidade produz regras compreensíveis?
- Uma divisão local faz mais sentido que uma relação global?
- O ensemble melhora a estabilidade?
