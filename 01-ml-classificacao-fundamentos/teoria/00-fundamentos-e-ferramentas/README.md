# Fundamentos e ferramentas

Esta pasta registra as explicações conceituais discutidas durante a revisão das ferramentas usadas no ciclo de Machine Learning.

Os arquivos devem responder, quando aplicável:

- qual problema a ferramenta resolve;
- qual objeto principal ela manipula;
- qual é a entrada e a saída;
- em que etapa do pipeline aparece;
- quando não devemos usá-la;
- quais erros conceituais são comuns.
