# Formulação do problema de Machine Learning

Esta pasta ensina a transformar uma necessidade de negócio em uma especificação testável de Machine Learning.

## Resultado esperado

Ao final, você deverá conseguir escrever uma especificação contendo: objetivo de negócio, unidade de previsão, população, momento da previsão, features disponíveis, variável-alvo, horizonte, saída, decisão, custos dos erros, baseline e critérios de sucesso.

## Convenções usadas

- **Fato:** afirmação fundamentada em fonte técnica, acadêmica ou documentação reconhecida.
- **Inferência:** conclusão derivada dos fatos e dos exemplos deste material.
- **Recomendação prática:** orientação de engenharia que deve ser validada com stakeholders e com o contexto operacional.

## Conexões da trilha

Esta etapa recebe a distinção entre classificação e regressão de `01-problema-de-classificacao` e prepara os contratos de dados e rótulos de `03-dados-e-rotulos`. Ela também antecipa data leakage, baselines, matriz de confusão, métricas, thresholds e operação em produção.
